# 📖 About the Project

Agency AI is a modern digital agency landing page designed to provide an engaging and professional online presence for technology and AI-focused businesses.

The project focuses on responsive design, clean user interface principles, reusable React components, and smooth user experience.

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Unnati-singh-ai/agency-ai.git
```

---

### Install Dependencies

```bash
npm install
```

---

### Run Development Server

```bash
npm run dev
```
